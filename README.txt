РОМЧИК v38

КАК ЗАПУСТИТЬ НА WINDOWS (без сервера, Node.js, прав администратора и брандмауэра)
1. Распакуй архив в любую папку.
2. Дважды кликни start.bat (он просто открывает index.html в браузере, ничего не слушает и не устанавливает).
3. В игре: кнопка 🌐 -> "Быстрая игра" или "Создать приватную сессию". Игроки соединяются напрямую
   между собой через интернет (WebRTC): у друга достаточно открыть свою копию игры и ввести код сессии.
   Нужен интернет (игра подгружает библиотеки и сервер знакомства игроков PeerJS).

ЕСЛИ ПРЯМОЕ СОЕДИНЕНИЕ НЕ РАБОТАЕТ (строгий NAT, мобильный интернет у обоих)
- Выложи игру в интернет на Render (DEPLOY.txt): ничего открывать на ПК не нужно.
- server-local.bat: C#-сервер только для этого ПК (без брандмауэра), нужен лишь если браузер не даёт открыть index.html напрямую.
- start-lan.bat: C#-сервер для Wi-Fi. Телефон и ПК открывают http://192.168.x.x:1220. Windows может спросить
  про брандмауэр, для разрешения нужен админ. Это единственный режим, где брандмауэр нужен.

Запуск и порт: RomchikServer.exe --port=3000 --no-browser [--lan]    (или переменная PORT)
Если порт занят, сервер сам берёт следующий.

ВАРИАНТЫ
- start-node.bat   — запуск старого сервера на Node.js (если Node стоит).
- DEPLOY.txt       — выложить в интернет на Render (server.js + package.json).

ЧТО В ИГРЕ
- Пассажиры в машине (E рядом с машиной другого игрока), до 3 пассажиров, в вертолёте 1.
- АК-47: клавиша 3 (или Q), зажать F — очередь.
- Общий мир: машины, трафик, взрывы и коктейли общие для всех игроков в сессии. Пешеходы и копы у каждого свои.
