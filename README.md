🚗 Лихой Город

Криминальный экшен в открытом мире, который запускается прямо в браузере — на ПК и на телефоне.

Ты новенький в городе. Вози посылки, угоняй тачки и не попадайся копам. Чем больше шухера, тем больше звёзд розыска.

3D-игра с видом от третьего лица в духе GTA, но с юмором и русским колоритом. Вся игра живёт в одном файле index.html, а для онлайна нужен только крошечный Node.js-сервер без зависимостей.

✨ Возможности
Задания. Забери посылку, довези до жёлтой точки и получи деньги.
Машины и дрифт. Газ, тормоз, ручник. За красивые заносы платят.
Вертолёт. Вызывается клавишей H, из него можно выйти прямо на земле.
Розыск. Звёзды, погони и кордоны. Из оружия есть пистолет и «коктейль Климова».
Здания. Магазин, кафе, квартира, спортзал, банк, больница, автосалон. В каждом свои действия: лечиться, спать, подрабатывать, тренироваться, покупать машины.
Риск. Можно ограбить кассу, взломать хранилище или поискать заначку.
Казино. Рулетка, фруктовый автомат с бонусными спинами, «псарня».
Тюрьма. Дай взятку, отсиди срок или рискни рулеткой (20% на свободу).
Карта. Центральный парк, мост через реку Берёзовку, деревня Берёзовка. Большая карта позволяет ставить метки и прокладывать маршрут.
Три персонажа: Ромчик, Андрей и Варя. Внешность настраивается в меню.
Графика и звук включаются и выключаются в меню.
🌐 Онлайн-режим

Свободная игра на 8 человек, как в GTA Online:

быстрая игра в открытой сессии или приватная сессия по коду;
видно других игроков, их машины и вертолёты;
чат, список игроков и стрельба по игрокам;
город у каждого свой, а игроки общие;
если хост выйдет, сессия закроется.
🎮 Управление
ПК
Клавиша	Действие
W A S D	идти / ехать
Shift	бежать
E	сесть в машину, выйти, войти в здание у двери
H	вызвать вертолёт
F	выстрел
1 / 2 / Q	пистолет / коктейль Климова
Пробел	прыжок (в машине — ручник)
N	большая карта
Tab	смена персонажа
Enter / T	чат
P	список игроков
Мышь / ← →	камера

В вертолёте: W/S — вперёд/назад, A/D — поворот, Пробел — вверх, Shift — вниз, E — выйти на земле.

Телефон
Левый палец — джойстик.
В машине слева стрелки руля, справа газ и тормоз.
Правая часть экрана — камера (свайп).
Тап по миникарте открывает большую карту.
Кнопки СЕСТЬ, ОГОНЬ, ОРУЖ., ПРЫЖОК и ВЕРТ. расположены на экране.
🚀 Быстрый старт

Нужен Node.js версии 18 или новее.

bash
node server.js

В консоли появятся адреса вида:

http://localhost:8080
http://192.168.x.x:8080

Открой любой из них на ПК и на телефоне (в одной Wi-Fi сети). На одном устройстве нажми 🌐 → «Создать приватную сессию», на другом введи код.

На Windows можно запустить start.bat.

Порт меняется так:

bash
PORT=3000 node server.js

Чтобы запустить другой HTML-файл с игрой:

bash
node server.js другой.html


🧱 Технологии
Three.js r128 — 3D-графика (WebGL)
Чистый HTML, CSS и JavaScript в одном файле, без сборки
Node.js — раздача игры и ретрансляция сообщений между игроками по WebSocket (собственная реализация RFC 6455, без зависимостей)
Мультиплеер: прямое соединение между игроками (WebRTC через PeerJS) или через server.js как ретранслятор
📁 Структура проекта

├── package.json

├── start.bat      # запуск на Windows
├── README.txt     # краткая инструкция

🛠 Если онлайн не работает
Проверь код сессии и убедись, что хост не закрыл вкладку.
Если прямое соединение не устанавливается (файрвол, NAT), запусти server.js и открой игру с его адреса: так надёжнее всего.
Сервер сигналов PeerJS может быть заблокирован в твоей сети. Попробуй VPN, другую сеть или мобильный интернет.
